퀴논 역설계 경과

논문 38편으로 온톨로지를 만들고, LLM이 그 근거로 퀴논을 제안하면 DFT가 평가해 결과를 되돌려 주는 루프를 돌렸습니다. 루프는 끝까지 작동했지만, 고수준 계산까지 통과한 목표 분자는 아직 없습니다.

계획 변경

계획이 바뀐 이유

  1. 개정 1–2xTB 평가자 + 대규모 닫힌 루프로 설계
  2. 개정 3DFT만 쓰기로 해서 비용 때문에 단발 생성(B안)으로 축소
  3. 개정 4B안은 역설계가 아니고 LLM이 후보 0개를 내서, 작은 닫힌 루프로 변경
  4. 개정 4.1적용 영역 확장, 빈자리 보충, 무작위 비교군 추가
  5. 개정 4.2루프는 상대 비교, 최종 후보만 고수준 확인, 실험표 재입력
맞교환 지도

평가한 분자 55개 (저수준 DFT)

오른쪽일수록 전자를 쉽게 받고(O₂에 강함), 아래일수록 CO₂를 세게 잡습니다. 목표는 오른쪽 아래 초록 영역(맞교환선보다 2σ 아래, O₂ 여유 ≥ 0.15 V)입니다. 빈 원은 CO₂가 떨어져 나간 분자입니다. 점에 마우스를 올리면 값이 보입니다.

평가한 후보의 평균 f

최고값은 사실상 같고, 평균은 LLM이 세 회차 모두 높습니다. 제안 시도는 LLM 19번, 무작위 52번이었습니다. 각 1회 실행이라 통계적 비교는 아닙니다.

분자저수준 f저수준 O₂ 여유고수준 E2 (V vs Fc)고수준 ΔG 결합, 1 M고수준 O₂ 여유판정

O₂ 여유는 실험 O₂/O₂•⁻ 전위(−1.23 V vs Fc, MeCN)를 기준으로 했고, 사전 통과 기준은 +0.15 V입니다. chloranil은 계산과 실험의 차이가 E2 −0.045 V, ΔG −2.9 kcal/mol로 방법 검증용입니다.

결론
된 것
  • 온톨로지 → LLM → DFT → 피드백 루프가 끝까지 작동
  • 실험값(chloranil)으로 계산 방법 검증
  • 할로젠 퀴논 범위에서는 맞교환을 넘기 어렵다는 확인
  • 버그 약 20개를 독립 검토로 찾아 수정
안 된 것
  • 목표 분자 발견 (고수준 O₂ 통과 0개)
  • LLM이 무작위보다 낫다는 입증
  • 피드백 효과 입증 (최고값은 피드백 전 1회차)
  • 신규성은 등록 범위(KG, Alherz 표) 안에서만
