# Phase 1: 질문(CQ) 초안

목적: 전기화학적 CO2 포집용 quinone 설계 (설계에 필요한 값을 논문에서 모아 비교하는 온톨로지)

- 상태: **확정 (2026-10-12, 사용자가 판단을 위임).** 필수 11개 확정, 권장 10개·선택 3개 보류, CQ25 제외. 시험 5편 판정은 `sample_papers.md`.
- 논문 수 열: 키워드로 센 **추정치**(대상 64편 / 경계선 29편). 초록 키워드 일치 수이며, 실제로 값이 있는지 확인한 것이 아님. 복합 질문은 여러 조건이 겹쳐 집계하지 않음.
- 필수 질문이 Phase 2 스키마와 Phase 4 추출 범위를 정함.

## 키워드 집계 주의
- 산소 안정성(CQ14)은 `O2`가 `CO2`에 걸리는 오류를 고쳐 23편으로 집계함.
- 환원 전위(CQ07)는 `potential` 단어를 쓰므로 부풀려졌을 수 있음. 용매·전해질(CQ13)도 `aqueous`, `salt` 등 흔한 단어를 써서 높게 나옴.
- 정확한 수는 Phase 1 시험 5편과 Phase 4 추출에서 확인함.
