# Phase 1: 결정 사항 (2026-10-12 확정)

사용자가 판단을 위임해서 아래와 같이 확정했다. 바꾸고 싶으면 이 표를 고치고, 바뀐 항목에 의존하는 Phase 2 이후를 다시 확인한다.

| 항목 | 결정 | 이유 |
|---|---|---|
| 목적 | 전기화학적 CO2 포집용 quinone 설계 | 사용자 지정 |
| 대상 논문 | 2020~2026년, 초록 판정 on_topic 64편 | 452편 합집합에서 선별 (3개 출처, DOI 중복 제거) |
| 경계선 29편 | 보관만. 스키마 안정 뒤 포함 여부 재검토 | CO2 환원, 흐름전지까지 범위가 번지는 것을 막기 위해 |
| 계산(DFT·가상 선별) | 담는다. 값마다 `basis`(experiment/computation) 필수 | CQ05, CQ23이 둘을 비교. 나중에 넣으면 스키마를 고쳐야 함 |
| 질문 | 필수 11개 확정, 권장 10개·선택 3개 보류, CQ25 제외 | 초록만으로 답이 안 나오는 조건 맞춤 비교를 필수로 늘리지 않기 위해 |
| 값의 조건 | 값마다 용매, 전해질, 기준 전극, 측정법을 붙인다 | 대상이 64편뿐이라 정확한 비교가 우선 |
