# 사람 검수 사용법 (human_review_40.csv)

엑셀로 열어서 각 행을 원문과 대조하고 마지막 3칸만 채웁니다. 약 1시간.

1. 원문 위치: 서버 `phase_3_corpus/text/<논문id>__*.txt` 에서 `===== PAGE <쪽> =====` 부분을 보거나, PDF의 해당 쪽을 엽니다. PDF는 연구용이라 서버 밖으로 공유하지 마세요.
2. 판정 칸에 `맞음`, `틀림`, `모름` 중 하나.
3. 틀림이면 둘째 칸에 무엇이 틀렸는지: 값 / 단위 / 화합물 / 조건 / 분류 중 하나 이상.
4. 메모는 자유.

무엇을 확인하나
- 측정값: 이 값이 이 화합물의 것인가(특히 열 방향 표), 단위와 부호가 맞는가, 조건(용매, 기준 전극, 분위기, 첨가제)이 이 값의 조건인가.
- 관찰: 인용문이 정말 그 결론(CO2Adduct, Carbonate, OxygenStable 등)을 뒷받침하는가, 다른 화합물 이야기는 아닌가.

표본 구성: 측정값 30(표 한 줄 인용 12, 첨가제 조건 9, 일반 9) + 관찰 10. 남은 오류 유형이 잘 드러나도록 위험한 쪽을 더 많이 뽑았으므로, 여기서 나온 틀림 비율은 전체보다 높게 나오는 것이 정상입니다.

판단 기준: 틀림이 약 10% 안팎이면 Phase 5로, 훨씬 높으면 규칙을 더 보강합니다. 모름은 틀림으로 세지 않고 따로 셉니다.
